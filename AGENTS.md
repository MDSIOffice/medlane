# Agent Notes

## Project Shape
- This is a static HTML/CSS/JS demo site; there is no `package.json`, build step, test runner, or framework config.
- Cloudflare Workers deploys static files from the repo root per `wrangler.jsonc`; edit the root files directly.

## Deploy Verification
- Use `npx wrangler deploy --dry-run` to validate deployment config without publishing.
- A correct dry run should read static files from the repo root.
- Publish with `npx wrangler deploy`; GitHub-connected Cloudflare deploys use the same Wrangler config.

## Editing Gotchas
- Proposal HTML is `medlane-system-proposal.html` in the repo root.
- The proposal PDF is a generated/static artifact, not automatically regenerated by repo scripts.
- Demo state in `script.js` uses browser `localStorage`; UI changes may appear stale until using the app's Reset Demo control or clearing local storage.
